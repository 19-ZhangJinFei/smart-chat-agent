# 使用说明

新建对话，输入后Enter发送，Shift+Enter换行，中文输入法选字不会误发送。侧栏改名、切换、删除；生成中暂停相关操作。刷新恢复历史。失败保留问题，刷新确认记录再重试。429需等待滑动窗口。

限流时页面显示等待秒数，发送、重试和会话操作暂时禁用，仍可编辑问题；倒计时结束后手动重试。429表示本轮未生成回复，不要求先刷新；同一问题重试会替换旧失败占位。网络中断等状态不明的失败需先点“核对记录”，确认历史后再决定是否发送，避免重复生成。成功聊天只需一次API请求，标题和问答直接从已保存的响应更新。

默认自动路由；普通模式闲聊且支持流式；智能体直接使用工具；自动先分类。标签只展示本轮工具。订单DD20240001—04、优惠券是模拟数据，未知业务数据明确告知。天气使用Tavily联网检索与Open-Meteo当前数据，来源URL可点击；先核对城市和数据时间。时间为系统北京时间；计算支持数字、括号和四则运算，不支持变量、函数、幂。

演示顺序：普通模式介绍姓名后追问；智能体查订单、北京天气、3874*239、时间、WELCOME10；工具查询后闲聊观察本轮标签；普通记录喜欢蓝色，智能体追问颜色；自动问Python再问优惠券；普通流式，改名刷新、重启恢复。
