# 阶段任务与验收标准

所有项目功能当前均未完成。对应任务由 GitHub Issues 跟踪。

## 阶段一：后端与持久记忆

跟踪任务：[Issue #1](https://github.com/19-ZhangJinFei/smart-chat-agent/issues/1)

- [ ] 检查 Python、Node、Docker 环境，建立独立虚拟环境与固定依赖。
- [ ] 配置中心、无密钥配置样例、分层结构与健康检查。
- [ ] 基本调用、流式调用、结构化抽取演示。
- [ ] 会话增删查改、多轮对话与数据库持久化。
- [ ] 参数校验、异常兜底与日志。
- [ ] 验证会话隔离、重启持久化和不存在会话的处理。

验收证据：接口验证记录、模型调用结果、重启前后数据记录；关键场景截图。

## 阶段二：智能体与前端

跟踪任务：[Issue #2](https://github.com/19-ZhangJinFei/smart-chat-agent/issues/2)

- [ ] 订单、天气、受限计算、时间工具。
- [ ] 持久检查点、仅本轮工具记录、模式切换记忆策略。
- [ ] 删除会话时同步处理相关记忆。
- [ ] Vue 会话侧边栏与聊天窗口，改名、切换与历史恢复。
- [ ] 加载与错误提示，工具调用展示。
- [ ] 自定义第五工具及提示词对照实验。

验收证据：真实工具选择、多轮追问、刷新恢复和界面联调记录。

## 阶段三：进阶与容器化

跟踪任务：[Issue #3](https://github.com/19-ZhangJinFei/smart-chat-agent/issues/3)

- [ ] 结构化意图分类，前端接入统一入口。
- [ ] SSE 缓冲解析、错误处理与完成状态。
- [ ] 限流及可信代理下客户端地址识别。
- [ ] 多工具请求、独立评估会话、工具选择正确率目标≥90%。
- [ ] Docker / Nginx / Compose 配置与数据卷。
- [ ] 容器部署、停启与重建后数据保留验证。

验收证据：实际评估输出、接口测试结果、真实部署状态与数据恢复记录。
