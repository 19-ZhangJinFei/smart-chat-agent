# 答辩演示与问答

本材料供本人复习与实际演练，不能据此声称本人已完成答辩准备。

前5分钟演示：新会话、姓名记忆、订单与计算、自动路由、普通流式、改名刷新。接着3分钟讲Vue→Nginx→FastAPI→模型/工具→双库，解释ID和版本。其余时间回答问题，总时长15分钟内。提前部署、检查网络与Key额度，准备真实证据，不现场安装。

## 核心问答

Function Calling：模型输出工具名称和JSON参数，Python执行工具，create_agent送回结果后继续模型调用。ReAct是推理、动作和观察的循环，本项目使用框架调度，不自写第二套循环。

计算器：语言模型生成数字可能错误，AST只接受允许节点，Decimal计算3874*239=925886。限制长度、节点、括号深度、数值规模，处理除零。

持久记忆：不是训练模型，而是再次提供保存上下文；thread_id等于会话ID，互相隔离。业务库存展示问答，检查点库存模型和工具执行链。

双库一致性：不具备原子跨库事务。成功轮次递增版本，普通模式或失败导致不一致，下轮从业务历史重建；失败清理。备份停止后端保证同一完成状态。

SSE：网络块不是字符或JSON边界，TextDecoder与事件缓冲避免中文断裂；DONE在落库成功后发送。只实现普通模式流式，自动和智能体使用完整响应。

限流：每IP队列记录60秒内20次，单调时钟避免系统时间跳动；第21次429含重试时间。Nginx覆盖伪造转发头，后端只信任指定代理网络；单worker内存重启清空。

Docker数据保留：镜像和容器只包含程序依赖，运行数据挂载宿主机。重建保留目录；备份使用SQLite API而非随意复制正在写入的文件。

评估结果：固定课堂10题当次10/10，补充4题通过，属于小样本。工具调用正确不等于答案正确，日期验收曾发现错误，优化和前后结果都保存。

工程增强：优惠券第五工具、受限计算、双库恢复、会话锁、断流提交策略、可追溯评估和备份恢复。不能虚称新模型算法。

个人复核：逐节理解并修改报告，亲自练习演示。未实现JWT、RAG、真实订单、公网/Vercel部署和智能体逐Token流式。

天气扩展：Tavily用于搜索天气相关网页；网页的更新时间不保证就是当前天气。Open-Meteo提供联网气象模型数据及预报，回答分别标注模型数据时间、联网查询时间和来源。它不是本地模拟，也不宣称为气象站现场实测；密钥、城市或上游异常不会被固定天气样例掩盖。
